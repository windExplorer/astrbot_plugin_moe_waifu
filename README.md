# ♥ 萌萌今日老婆

> 适用于 AstrBot 的每日二次元老婆抽卡插件：每天从角色库里确定性抽出一位「今日老婆」，
> 萌绘生成专属立绘（并沉淀进立绘库），渲染成萌系竖版卡片发到群里。

![依赖](https://img.shields.io/badge/%E7%A1%AC%E4%BE%9D%E8%B5%96-%E8%90%8C%E7%BB%98%20v7.7.58%2B-red)

---

## ⚠️ 硬依赖：萌绘（先读这段）

本插件的立绘由 **萌绘（`astrbot_plugin_comfyui_anima`）** 生成，属于**硬依赖**：

- 请先安装并配置好萌绘（**v7.7.58 及以上**）与 ComfyUI 后端，再使用本插件；
- **需要生图而萌绘不可用（未安装 / 超时 / 失败）时，插件会报错且不出卡**——
  立绘就是产品本体，我们刻意不做「无图的降级卡片」；
- 角色立绘攒满配额后，从立绘库直接取图，**不再需要萌绘在线**；
- 生图走萌绘统一的跨插件契约（`external=True`），画风 / LoRA / 工作流 / 图库
  全部由萌绘统一管理，本插件不会自行连接 ComfyUI。

## 玩法

| 指令 | 说明 |
| --- | --- |
| `/今日老婆`（别名 `/老婆`） | 抽今天的老婆。一人一天一位：种子（日期+用户号+盐）决定，重启不变、无法刷 |
| `/换老婆` | 重新抽一位。受「每日换老婆次数」限制（默认 1 次，可配 0=关闭） |
| `/老婆帮助` | 帮助 |

**角色库管理 / 试画 / 立绘库维护都在 WebUI「工坊」里做**：AstrBot Dashboard →
插件 → 萌萌今日老婆 → 打开插件 Page（仅管理员）。试画不走聊天指令。

**卡片内容**：角色立绘全幅打底 + 角色应援色渐变面板：名字、作品、分类/稀有度徽章、
一句印象语、「今日同款 N 人」（本群今天抽到同一角色的人数）、「第 N 次抽到她」（累计）、
日期与重抽标。

**同款机制**：同群同日抽到同一角色的人，共享同一张立绘、互相可见——这是话题来源，
不是竞争机制。

## 立绘库（核心机制）

每个角色有一个立绘配额（默认 5 张）：

- **未满配额**：当天第一个抽到她的人触发生成（萌绘 20~120 秒，会先发「正在召唤」提示），
  成功后**存档入库**；当天再有人抽到 → 直接复用这张图；
- **满配额**：按种子从库存随机取一张，**零绘图秒出**，完全不消耗 ComfyUI 算力；
- 立绘只增不淘汰；后续版本的工坊页可以删掉画坏的图，删除后低于配额会自然补生。

## 角色库（一卷一 JSON）

角色库在 `data/plugin_data/astrbot_plugin_moe_waifu/pools/`，**一个 JSON 文件 = 一卷**：

```json
{
  "pack": "anime",
  "title": "动漫卷",
  "enabled": true,
  "entries": [
    {
      "id": "hatsune_miku",
      "name": "初音未来",
      "series": "VOCALOID",
      "category": "anime",
      "tier": "S",
      "strategy": {"type": "base"},
      "tags_en": "hatsune miku, twintails, teal hair, headset, sleeveless shirt",
      "quote": "初次见面，我是初音未来！",
      "color": "#39C5BB",
      "verified": false
    }
  ]
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `category` | `anime` 动漫 / `gal` galgame / `game` 游戏 / `other` 其他 |
| `tier` | 仅作卡片徽章展示（S/A/B…），不参与抽卡权重 |
| `strategy` | **画法策略**：`base`（底模认识的角色 tag 直出）/ `lora`（`{"type":"lora","loras":["xxx:0.8"]}`）/ `img2img`（`{"type":"img2img","ref":"<官方立绘 URL 或本地路径>"}`） |
| `tags_en` | 英文 danbooru 角色标签（角色 tag + 系列 tag + 稳定外观特征）。括号要写成 `\(` `\)` 转义 |
| `verified` | 试画验证过「画得对」才参与抽卡（可在配置里放宽） |
| `color` | 角色应援色（hex），整张卡随它定色 |

**怎么保证画对？** 策略是试出来的，不是配置出来的：

1. 在工坊「试画台」选角色试画——动漫 / 二游主流角色底模基本都认识（base 一步过）；
2. 画错了（不像本人）→ 在「角色库」补正 tags，或把策略改成 `img2img` 挂一张官方立绘
   参考图（干净单人图，组图/Q版不可用），重绘强度默认 0.65，再试；
3. 画对了 → 试画台点「画对了，标记 verified」，从此参与群内抽卡；也可以
   「存入立绘库」提前沉淀。

工坊四页签：**角色库**（增删改查 / 分卷分类筛选 / verified 开关）、**试画台**、
**立绘库**（缩略图网格 / 删坏图 / 单角色补一张）、**分群绑定**（每行 `群号=卷名,卷名`）。

首启时包内自带 20 条种子卷（动漫 8 / gal 4 / 游戏 8）会复制到 data 目录
（**已有的卷不会被覆盖**），此后 data 目录就是唯一真源，升级插件不丢库。

**分群角色库**：配置 `group_pools` 每行一条 `群号=卷名,卷名`，该群就只在指定卷里抽；
留空 = 全部启用卷。

## 配置项（插件配置页）

| 配置 | 说明 | 默认 |
| --- | --- | --- |
| 时区 | 「今天」按此时区计算 | Asia/Shanghai |
| 种子盐值 | 与日期、用户号一起派生结果，勿随意改 | moe-waifu |
| 停用群 | 每行一个群号 | 空（全开） |
| 分群角色库 | 每行 `群号=卷名,卷名` | 空（全卷） |
| 每日换老婆次数 | 0 = 禁用换老婆 | 1 |
| 每角色立绘配额 | 满了之后从库里取图不再生图 | 5 |
| 未验证角色可抽 | 关闭时只有 verified 角色会被抽到 | 关 |
| 生图工作流 | 留空用萌绘默认 | 空 |
| 立绘尺寸 | 生成图与卡布一致 | 700×1200 |
| 生图超时 | 超时报错不出卡 | 120 秒 |
| 负面提示词 | 内置兜底排除男性特征与 NSFW，可覆盖 | 内置 |
| 重绘强度 | img2img 策略用 | 0.65 |
| 召唤提示 | 生成时先发一句过程提示 | 开 |

## 安装

1. 安装并配置 **萌绘 v7.7.58+** 与 ComfyUI 后端（`external` 跨插件契约自该版本引入）；
2. 通过 AstrBot 插件市场或 zip 安装本插件，重启 AstrBot；
3. 发 `/今日老婆` 验证：首张卡生成需要等萌绘（20~120 秒），之后同角色当日秒出。

## 数据与文件

- 库文件：`data/plugin_data/astrbot_plugin_moe_waifu/waifu.db`（SQLite）
- 角色库：`data/plugin_data/astrbot_plugin_moe_waifu/pools/*.json`
- 立绘库：`data/plugin_data/astrbot_plugin_moe_waifu/portraits/<角色id>/*.png`
- 参考图（img2img）：条目 `strategy.ref` 支持 URL 或本地路径

## 已知边界

- `img2img` 参考图仅本地缓存用于生图，不会二次配布；
- `base` 策略的效果取决于萌绘所配底模对 danbooru 角色 tag 的认知
  （推荐 NoobAI / Illustrious 系动漫工作流）；
- 未配置verified 角色前，若库里没有可用角色会提示「老婆库还是空的」。
